# ขั้นตอนการทำงาน
1. **การจัดวางและระยะห่าง:** ใช้พื้นหลังโทนสว่างสะอาดตา (เช่น `bg-slate-50`) คู่กับการ์ดสีขาว (`bg-white border border-slate-200 rounded-xl shadow-sm`) และเว้นระยะห่าง Padding ให้โปร่งไม่อึดอัด
2. **ตารางข้อมูล ERP:** จัดหัวตารางให้อ่านง่าย (`bg-slate-50 text-slate-600 font-medium`), เพิ่ม `hover:bg-slate-50` ในแต่ละแถว, จัดตัวเลขจำนวนเงินและสต็อกชิดขวา (`text-right tabular-nums`) และข้อความชิดซ้าย
3. **ป้ายสถานะ (Status Badges):** ใช้ป้ายทรงมน (`rounded-full px-2.5 py-0.5 text-xs font-medium`) แยกสีตามสถานะชัดเจน เช่น เขียว (อนุมัติ/สำเร็จ), เหลืองอำพัน (รอดำเนินการ), แดง (ยกเลิก/เกินงบ), เทา (ร่าง)
4. **ความสมบูรณ์ของหน้าจอ:** รองรับการแสดงผลบนหน้าจอขนาดต่างๆ และใส่ไอคอนสื่อความหมายคู่กับปุ่มหลักเสมอ

# ข้อห้าม (Do not)
- ห้ามใช้สีฉูดฉาดเกิน 2 สีหลักในหน้าจอเดียว (เน้นสีหลักของแบรนด์คู่กับสีสถานะที่จำเป็นเท่านั้น)
- ห้ามทำปุ่มกดหรือช่องกรอกข้อมูลติดกันโดยไม่มีระยะห่าง (`gap` หรือ `space-y`)
