# ขั้นตอนการทำงาน
1. ค้นหาเฉพาะบรรทัดหรือฟังก์ชันที่เกี่ยวข้องด้วยเครื่องมือค้นหาแทนการอ่านไฟล์ขนาดใหญ่ทั้งไฟล์
2. แก้ไขโค้ดแบบเจาะจงเฉพาะจุด (Diff/Patch) หลีกเลี่ยงการเขียนโค้ดซ้ำทั้งไฟล์หากไม่มีความจำเป็น
3. สรุปสิ่งที่แก้ไขเป็นข้อสั้นๆ กระชับ ไม่อธิบายทฤษฎีพื้นฐานยาวเกินความจำเป็น

# ข้อห้าม (Do not)
- ห้ามเปิดอ่านไฟล์ในโฟลเดอร์ `dist/`, `node_modules/` หรือไฟล์ `package-lock.json`
- ห้ามแสดงโค้ดซ้ำในช่องแชตหากได้แก้ไขลงในไฟล์เรียบร้อยแล้ว
