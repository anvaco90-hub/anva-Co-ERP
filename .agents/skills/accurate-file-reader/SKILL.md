# ขั้นตอนการทำงาน
1. ตรวจสอบรายการ `import` ด้านบนของไฟล์ที่กำลังจะแก้ เพื่อดูว่าเรียกใช้ Component, Hook หรือ Supabase helper ตัวไหนอยู่
2. อ่านโค้ดให้ครอบคลุมทั้งฟังก์ชันและขอบเขตของ State/Props ก่อนแก้ไข ห้ามอ่านแค่บางบรรทัดแล้วเดาโครงสร้างที่เหลือ
3. ค้นหาจุดที่เรียกใช้ฟังก์ชันหรือ Component นี้ในไฟล์อื่นด้วยเสมอ เพื่อให้แน่ใจว่าการแก้พารามิเตอร์ไม่ทำให้หน้าอื่นเกิด Error

# ข้อห้าม (Do not)
- ห้ามสมมติชื่อตัวแปร Props หรือชื่อฟังก์ชันจากไฟล์อื่นโดยไม่เปิดอ่านไฟล์ต้นทางก่อน
- ห้ามลบโค้ดหรือตัวแปรที่ดูเหมือนไม่ได้ใช้จนกว่าจะค้นหาทั่วทั้งโฟลเดอร์ `src/` แล้ว
