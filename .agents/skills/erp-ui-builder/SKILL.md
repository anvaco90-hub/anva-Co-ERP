# ขั้นตอนการทำงาน
1. ตรวจสอบคอมโพเนนต์และสไตล์ที่มีอยู่เดิมใน `src/` เพื่อใช้โครงสร้าง Layout ปุ่ม และสีให้สอดคล้องกัน
2. แสดงสถานะ Loading, Empty State (เมื่อไม่มีข้อมูล) และ Error State ให้ครบทุกหน้าที่มีการดึงข้อมูล
3. จัดรูปแบบตัวเลขจำนวนเงินและยอดสต็อกให้มีเครื่องหมายคั่นหลักพันและทศนิยมที่เหมาะสมกับงานบัญชีและคลังสินค้า

# ข้อห้าม (Do not)
- ห้ามสร้างสไตล์ CSS แยกไฟล์ใหม่หากสามารถใช้คลาสมาตรฐานของ Tailwind CSS ที่มีอยู่ได้
- ห้ามปล่อยให้ปุ่มบันทึกกดซ้ำได้ขณะกำลังส่งข้อมูล (ต้อง disable ปุ่มระหว่าง loading)
